A host is a `Request` in and a `Response` out. Binding one to a framework is a
line, which is why there is no per-framework adapter to install.

Anything the route table does not claim falls through to your own routes, so an
API lives alongside the pages rather than behind them.

The same handler runs under `Bun.serve`, Elysia, Deno and Workers. The examples
in this repository are one application served four ways, and only the entry
file differs.
