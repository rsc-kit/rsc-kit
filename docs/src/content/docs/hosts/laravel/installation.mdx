The Laravel host drives the `@rsc-router/core` engine from PHP. You install
both: the Composer package for the bridge, and the npm package for the build.

## Requirements

- **PHP 8.3+** with the `sockets` extension
- **Laravel 13+**
- **Bun or Node** — either runs the worker and the build. `RSC_RUNTIME` picks one; Bun is the default and `php artisan rsc:install` can vendor its binary on hosts that lack one.
- **React 19**

## 1. Install the Composer Package

```bash
composer require larabun/laravel-rsc
```

This installs the PHP bridge, service provider, Artisan commands, and the Bun worker script.

## 2. Publish the Configuration

```bash
php artisan vendor:publish --tag=rsc-config
```

Creates `config/rsc.php` where you configure the socket path, worker count, and RSC options.

## 3. Install JavaScript Dependencies

```bash
bun add @rsc-router/core react react-dom
bun add -d vite @vitejs/plugin-rsc @types/react @types/react-dom
```

`@rsc-router/core` brings the Vite plugin, the worker and the client runtime.
The build runs your project's own `vite.config.ts`, so add the plugin there:

```ts title="vite.config.ts"
import { defineConfig } from 'vite';
import { rscRoutes } from '@rsc-router/core/vite';

export default defineConfig({
  plugins: [rscRoutes()],
});
```

`rsc:build` passes Laravel's conventions to it through the environment — the
source directory, the import alias, the host global's name — so nothing here
needs repeating them.

Then add the build and dev scripts to your `package.json`:

```json title="package.json"
{
  "scripts": {
    "build": "php artisan rsc:build",
    "dev": "php artisan rsc:dev"
  }
}
```

`bun run build` builds the bundles and prerenders what can be prerendered. `bun run dev` watches, rebuilds and runs the worker.

## 4. Environment Configuration

Add the following to your `.env` file:

```env title=".env"
RSC_ENABLED=true
RSC_SOCKET=/tmp/my-app-bridge.sock
```

## 5. AI Skills (Laravel Boost)

If you use `Laravel Boost`, discover the RSC development skill so your AI assistant knows the conventions:

```bash
php artisan boost:update --discover
```

Select `larabun/laravel-rsc` when prompted. This installs the `rsc-development` skill with file-based routing conventions, server actions, Form/useForm patterns, and the build pipeline.

## 6. Create Your First Page

Routes are files. Create an `app/` directory inside `resources/js/rsc/` with a root layout and a page:

```tsx title="resources/js/rsc/app/layout.tsx"
export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <head>
        <meta charSet="utf-8" />
        <meta name="viewport" content="width=device-width, initial-scale=1" />
      </head>
      <body>
        <nav>My App</nav>
        <main>{children}</main>
      </body>
    </html>
  );
}
```

There is no Blade shell. The root layout renders the whole document, and the
build injects the bootstrap script and stylesheet links into it.

```tsx title="resources/js/rsc/app/page.tsx"
export default function Home() {
  return <h1>Hello</h1>;
}
```

That's it — `app/page.tsx` maps to `GET /` and is automatically wrapped by `app/layout.tsx`. See [File-Based Routing](/guides/routing) for the full convention.

## 7. Start Development

```bash
php artisan rsc:dev
```

One command: it builds the bundles, watches for changes, and runs the worker. It automatically rebuilds when you change files and restarts the worker when bundles update.

For production, use `bun run build` followed by `php artisan rsc:serve`. See [Deployment](/hosts/laravel/deployment) for details.
